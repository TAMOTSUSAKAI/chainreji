==============================================================
 チェーンレジ — 暗号資産お会計ツール（無料・非公式）
==============================================================

飲食店などの店頭で、JPYC（日本円ステーブルコイン）・USDT・
BTC・ETH・SOL でのお支払いを受け付けられるお会計アプリです。
金額を入力してQRコードを見せるだけ。入金はブロックチェーンを
直接確認して自動検知します。売上データやお金が第三者のサーバー
を経由することはありません。

--------------------------------------------------------------
1. 同梱ファイル
--------------------------------------------------------------
  index.html  … アプリ本体（これ1枚で動きます）
  api.php     … サーバー保存用（任意。複数端末で共有したい場合）
  README.txt  … この説明書
  LICENSE.txt … ライセンス（MIT）

  ▼おまけ（レジとは独立して動く別ページ）
  traffic-law.html      … 道路交通法・運送の制度改正まとめページ
  ogp-traffic-law.png   … 上記ページのSNSシェア用画像
  law-check.php         … 公式サイトの更新を見張って知らせる（任意）

--------------------------------------------------------------
2. 必要なもの
--------------------------------------------------------------
  ・ホームページを置けるサーバー（レンタルサーバー等）
    ※HTTPS対応を強く推奨（お客様のウォレット連携に必要）
  ・自分のウォレット
    - JPYC/USDT/ETH … MetaMask等のアドレス（0xから始まる）
    - BTC … ビットコインのアドレス（任意）
    - SOL … Solanaのアドレス（任意）
  ・JPYCを日本円に換金する場合は JPYC EX のアカウント
    （https://jpyc.co.jp ／本人確認が必要）

--------------------------------------------------------------
3. 設置手順
--------------------------------------------------------------
  (1) index.html をサーバーの好きな場所にアップロード
  (2) ブラウザで開き、「設定」タブで以下を入力して保存
      ・店名（レシートに印字されます）
      ・受け取りウォレットアドレス
      ・ネットワーク（迷ったらPolygonのまま）
  (3) まず自分のウォレットから100円程度を送って、
      「済」画面が出ることを必ず確認してください

  ▼複数の端末（レジ用タブレット＋スマホ等）で共有する場合
  (4) api.php を index.html と同じフォルダにアップロード
  (5) api.php をエディタで開き、$SYNC_KEY = 'CHANGE-ME' を
      自分だけの合言葉に変更
  (6) アプリの「設定」→「サーバー保存の合言葉」に同じ文字列を
      入力して保存

--------------------------------------------------------------
4. 使い方
--------------------------------------------------------------
  お会計 … 商品をタップ→「QRコードで請求する」→通貨を選ぶ
           →お客様がスマホでQRを読み取って支払い
           →着金すると自動で「済」画面になります
  商品   … メニューの登録・編集・削除
  売上   … 売上一覧／ブロックチェーン上の入金履歴／レシートPDF
  相場   … BTC・ETH・SOL・USDTの円建てチャート
  設定   … 店名・アドレス・ネットワーク・サーバー保存

--------------------------------------------------------------
5. おまけ：道路交通法 改正なび（traffic-law.html）
--------------------------------------------------------------
  毎年変わる道路交通法と、軽貨物運送に影響する制度（貨物自動車
  運送事業法・フリーランス新法など）を年表にまとめたページです。
  レジ本体とは独立して動くので、単独で公開できます。

  ▼設置手順
  (1) traffic-law.html と ogp-traffic-law.png を、同じフォルダに
      アップロード（レジと別のフォルダでも構いません）
  (2) traffic-law.html をエディタで開き、次の3か所を書き換える
      ・ファイル冒頭の <link rel="canonical"> と og:url の
        example.com を、実際の公開先アドレスに
      ・<script> 内の OWNER   … 運営者名（例: '酒井運送'）
      ・<script> 内の CONTACT … 連絡先メールか問い合わせページURL
      ※書き換えなくても表示・動作はします
  (3) ブラウザで開いて、検索・絞り込み・並べ替えを確認

  ▼公式サイトの更新を自動で見張る（任意・law-check.php）
  法改正そのものを自動でページに反映することはできませんが、
  「公式サイトに新しいお知らせが出たら教える」ところまでは
  自動化できます。

  (1) law-check.php を同じフォルダにアップロード
  (2) エディタで開き、次の2か所を変更
      ・$MAIL_TO … 通知を受け取るメールアドレス
      ・$RUN_KEY … 自分だけの合言葉（必ず変更）
  (3) サーバーの管理画面で cron を設定する
      例）毎週月曜の朝8時に実行
      0 8 * * 1  /usr/bin/php /home/ユーザー名/public_html/law-check.php
      cronが使えないサーバーなら、ブラウザで次を開けば手動実行できます
      https://例.com/law-check.php?key=合言葉

  警察庁・国土交通省・NASVAのページを見に行き、「改正」「施行」
  「軽貨物」等を含む新しいお知らせが増えたときだけメールが届きます。
  初回は基準を記録するだけで、メールは送りません。
  記録と実行ログは law-check-data/ に保存されます。

  ※このスクリプトはページの中身を書き換えません。何をどう載せるかは
    必ず人が判断してください（金額や施行日の誤りは読む人に迷惑がかかります）。

  ▼掲載内容を増やす・直す
  <script> 内の LAWS という一覧に1件書き足すだけで、年表・検索・
  重要度順・通知・構造化データのすべてに反映されます。
  日付を未来にすると、自動でカウントダウンと通知の対象になります。
  更新したら UPDATED の日付も直してください。
  最終更新から半年以上たつと、ページの先頭に「情報が古い可能性がある」
  という警告が自動で出ます（読む人が古い内容を信じないための安全策）。

  ▼できること
  ・キーワード検索／対象者・年での絞り込み
  ・「軽貨物の重要度順」での並べ替え（★3段階）
  ・施行日・対応期限のカウントダウンとブラウザ通知
  ・Googleカレンダー登録、カレンダーファイル(.ics)の書き出し
  ・絞り込んだ状態での印刷（閉じたカードの中身も印刷されます）
